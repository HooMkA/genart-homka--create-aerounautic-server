# Способ простой и единственный  
 Качаете архив инстанса(экземпляра)  
У вас есть выбор скачать сразу с лодами для мода Voxy(на далёкую прорисовку) или без них, если не будете им пользоваться.    

[Для Prism c лодами](https://pack.jolly-roger.digital/extras/Aero-Prism-LODS.zip)  
[Для PolyMC с лодами](https://pack.jolly-roger.digital/extras/Aero-PolyMC-LODS.zip)  
  
[Для Prism без лод](https://pack.jolly-roger.digital/extras/Aero-Prism.zip)  
[Для PolyMC без лод](https://pack.jolly-roger.digital/extras/Aero-PolyMC.zip)
  
  
И лайт версия для тех у кого ВСЕГО 8 гигов оперативы. Если у вас 8 на майн, то и основную потянет.  
Максимально урезанная, ни шейдеров, ни прорисовки, ни половины структур в одиночном мире. Зато стартует на 5.5 гигах  
  
[PolyMC Лайт](https://pack.jolly-roger.digital/extras/Aero-PolyMC-LIGHT.zip)  

<br>  

1. Открываете ваш лаунчер Prism/PolyMC(никакой хуйни в виде TLauncher или обычного майновского). Открываете сверху папки `Папки` -> `Папка со сборками/экземплярами ` -> и забрасываете туда ПАПКУ ИЗ АРХИВА!! Не сам архив! Не содержимое папки! А саму ПАПКУ
2. Перезапускаете лаунчер. У вас появляется новый инстанс.
3. Запускаете, выбираете опциональные моды. Ждёте скачивания
4. Вуаля теперь у вас сборка, которая всегда будет обновлена и ничего руками делать не нужно.
