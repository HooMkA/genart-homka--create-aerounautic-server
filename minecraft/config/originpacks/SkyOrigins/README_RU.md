# SkyOriginsBalance V2

Положить ZIP в:
C:\All\Minecraft\game\config\originpacks\

Изменения:
- Используются встроенные ID neoorigins:human, neoorigins:dwarf, neoorigins:avian, neoorigins:merling.
- Avian больше НЕ имеет neoorigins:avian_no_fall_damage.
- Avian сохраняет neoorigins:avian_slow_fall и neoorigins:avian_no_hunger_sprint.
- Avian стартует на 1 сердце меньше.
- Avian/Dwarf имеют высотные ограничения сна.
- Для полного запрета сохранения кровати на неверной высоте нужен KubeJS-скрипт skyorigins_bed_rules.js.


## V3 change

Avian Tier 2 / Ascended: средние штрафы ниже Y=80 полностью исчезают. Глубокий штраф ниже Y=48 теперь заменён только на Weakness I без Mining Fatigue и exhaustion.
